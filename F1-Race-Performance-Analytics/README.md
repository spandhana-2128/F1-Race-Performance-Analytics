# F1 Race Performance & Strategy Analytics

A data analytics and machine learning project analyzing Formula 1 race performance,
tyre strategy, pit stops, qualifying-to-race performance, and race outcomes.

## Planned stack
- Python / Pandas / NumPy
- SQL
- FastF1 / F1 session data
- Scikit-learn
- Power BI

## Project stages
1. Data collection and exploration
2. Data cleaning and feature engineering
3. SQL-based race analytics
4. Driver / constructor performance analysis
5. Tyre and strategy analysis
6. Race-performance prediction
7. Power BI dashboard
8. Documentation and GitHub publication

## Data
Raw and processed data are intentionally not bundled in this starter package.
They will be added during the project after we select the required 2026 sessions.
