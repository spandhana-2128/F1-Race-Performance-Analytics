# Power BI Dashboard

The Power BI dashboard provides an interactive analysis of Formula 1 race performance and tyre strategy across the Australian, Chinese, and Japanese Grand Prix.

## Dashboard Pages

### 1. Overview

High-level driver and race performance metrics including:

- Representative average lap time
- Best lap time
- Total laps
- Driver count
- Driver pace comparison
- Race and driver comparison matrix

### 2. Tyre & Strategy Analysis

Analysis of:

- Maximum stint length by driver
- Maximum stint length by tyre compound
- Average tyre pace
- Tyre-life performance
- Race-level strategy differences


### 3. Race Performance

Analysis of:

- Driver finishing positions
- Representative average lap time
- Lap-time consistency
- Detailed race and driver comparisons



Open the `.pbix` file using Power BI Desktop to interact with the report.
